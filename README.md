# 萬妖文書版 / Wanyao Learning Archive

Eight learning stations with Traditional Chinese and English descriptions.

Website: https://ro222291.github.io/pcrlearing/

## Deployment
GitHub Pages publishes `main` from `/ (root)`. The standalone `index.html` embeds CSS, JavaScript, screenshots and QR codes so no build or asset-path configuration is needed. External learning sites and videos retain their original languages.
